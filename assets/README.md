# 🎵 Spotify Clone

A responsive Spotify-inspired music streaming website built using HTML and CSS.

## 🚀 Features

- 🎵 Spotify-inspired user interface
- 🏠 Home page
- 🔍 Search section
- 📚 Your Library section
- 🎶 Trending songs section
- ▶️ Music player interface
- ⏯️ Play/Pause controls
- 📱 Responsive design
- 🎨 Dark theme inspired by Spotify

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
